# Beeston Hockey 2026/27

Unofficial fixtures, results and league tables for every Beeston Hockey Club team, published with GitHub Pages.

- `index.html` – the site (open the Pages link in Settings → Pages).
- `data/` – fixtures, league tables and teams as JSON.
- `scraper/scrape.py` – reads England Hockey's public team and league pages.
- `.github/workflows/refresh.yml` – runs the scraper early on Sunday and Monday, commits new data and republishes. Run it by hand from the Actions tab with **Run workflow**.

Not produced by Beeston Hockey Club. Data from englandhockey.co.uk.
